              Operários (cota ociosa trabalhando)
              
            

            

              
              
              
            

            
—

            

              A cota gratuita zera todo dia — o que não for usado, perdeu. Os operários pegam essa
              capacidade ociosa e põem os modelos gratuitos para ler o cofre e destilar regras.
              Regra entra no prompt de todos, inclusive dos pagos. Nunca usa a sua conta Puter.
            

          

          

            

              Worker de busca passiva (CPU + RAM, custo zero)
              
            

            

              
              
            

            

              
              
            

            
—

            

              O script é Python puro (só a stdlib): roda no Kaggle, no GitHub Codespaces ou no seu PC.
              Sem GPU, sem chave, sem cota — ele só baixa, limpa e escreve um pack que você importa.
              É o trabalho pesado saindo de graça das suas máquinas: CPU + RAM fazem a varredura,
              a cota só entra para destilar, e a GPU só para treinar um modelo seu.
            

          

          

            

              Ingestão contínua (links, sem parar)
              
            

            

              
              
            

            

              
              
              
              
            

            
—

            

              Baixa a página, tira o HTML e indexa no cofre. Custo de IA: zero — não chama modelo
              nenhum, não gasta cota de ninguém. Limites propositais: 400 na fila, 25 links por
              página, 2 saltos, ~2,5s entre páginas. Varrer a internet inteira (archive.org = +100 PB)
              não é possível, e treinar texto bruto da web piora o modelo — o que cresce é o cofre.
            

          

          

            O pack entra no motor neural como conhecimento pesquisável: quando a pergunta tem a ver,
            o trecho certo entra no prompt de qualquer modelo. Não é treino de peso — isso é o
            nó com GPU (aba VM › Exportar dataset), e muda um modelo seu, não os dos outros.
          

        

        

          

            As duas cotas e a direção
            
          

          
—

        

        

          
          
        

        

          Contadores anônimos: o site guarda só números (quantas sessões, quantos pedidos,
          quantos foram grátis). Nunca token, e-mail, nome ou id de conta.
        

      

      
      
O armazém existe para as contas do dono do site (as suas). A conta de
        quem visita fica só no navegador daquela pessoa e atende os pedidos dela: o crédito de
        quem se autentica é gasto por quem se autentica. Não existe captura automática — e com este
        interruptor desligado, nem o botão de capturar funciona.

         Ninguém precisa criar conta no Puter nem no HF para usar o site.
