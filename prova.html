O que este teste prova — e o que ele não prova
Prova: a cota gasta é sempre a de quem está usando; nenhum token cruza de um navegador para o outro; a conta de quem visita não entra no armazém; o armazém guarda só as contas do dono.

Não prova (e não tem como): que o crédito de uma conta "sobe" quando alguém se cadastra no Puter. Esse fluxo não existe — a permissão de uso é da conta autenticada e não é transferível para um app. Por isso nenhuma tela deste site promete isso.
